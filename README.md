# KÖR

Magyar nyelvű Next.js bemutatóoldal egy újrahasználható bögréhez.

## Helyi futtatás

Node.js 20.9 vagy újabb szükséges.

```sh
npm install
npm run dev
```

Az oldal a http://localhost:3000 címen érhető el.

## Statikus kiadás

Az `npm run build` az `out/` mappába exportálja az oldalt. A mappa tartalma statikus tárhelyről kiszolgálható.
